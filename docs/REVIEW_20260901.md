## 3) 🎮 操作

### 核心参数

- `player.gd:12` `WALK 5.5 / SPRINT 8.6(1.56×) / ACCEL 30 / AIR 14 / GRAVITY 22 / JUMP 7.6 → 腾空 0.69s/1.31m / SWIM 4.8 / GLIDE 8.2`
- `weapon.gd:11` rifle 108 DPS / dmr 87.5 / smg 138.7(近距×1.3) / shotgun 70 / lmg 88；`bloom +0.15 上限 1.2 衰 4.0`
- `project.godot:32` deadzone 全 0.5 + 7 处 Joy 冲突；`vehicle/horse/motorcycle/raft` 全 `is_key_pressed(KEY_W)`

### 判定

- **地面磁吸**：`5.5/30=0.18s` 急停无惯性；**空中肥皂**：`AIR_ACCEL 14 = 46%` 地面，转向同地面
- **Bloom 过重**：rifle 机瞄 0.45° + bloom 0.6°(4 发后)=1.05°，100m 直径 3.6m，`bloom 0.3s 归零` vs 540RPM `0.11s/发` 永满
- **后坐不可学习**：随机偏航 `±0.3*deg` 无固定弹道
- **缓冲缺失**：无 coyote/buffer，楼梯 `floor_snap 0.5` 丢跳 ~15%；无射击缓冲，连点丢发
