## 四、新增门禁建议（本轮教训）

1. **重载门禁**：`--reloadtest` 720 帧（≥2 次重载）+ 开火——本轮两个最重的 bug（decal 悬垂、低通泄漏）都只在"按 R 重开后"发作，既有门禁覆盖不到。
2. **fresh import 断言**：CI/验证前必跑 `--import` 并断言 SOUNDS 全键非 null——13 个 wav 缺 `.import` 让整批音效在所有"全绿"报告里哑火。
3. **sfx WARN 不限量**：缺键/空流必打日志（已实现），验收脚本 grep `WARN missing` 应为 0。
4. **修复自证**：改状态机的修复必须带"反例断言"（如警觉修复需断言 bot 会还击），否则修 A 崩 B。
